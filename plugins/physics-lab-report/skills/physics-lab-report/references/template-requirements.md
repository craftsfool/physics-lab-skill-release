# 报告栏目与逐项验收

## 先读完整栏目，再列提纲

用户报告纸的栏目标题、括号说明、脚注及教师补充要求共同决定内容；通用模块表不能代替实际模板。撰写前读清每页，将括号内的并列要求拆成独立检查项。模糊文字先核对，不能只识别栏目名就开始写。星号是否表示选做须以模板或教师说明为准，不能自行省略。

为本次需要的模块建立内部清单：`页/栏目 → 要求项 → 材料依据 → 成品位置 → 完成状态`。只记录用户要求范围内的内容；范围外标注不在本次任务中。尚缺材料的必填项标注待补，不得标成完成。检查表属于工作记录，默认不进入打印正文。

下表是附带四页模板的拆分示例；其他学校或新模板以实际文字为准。

| 栏目及说明 | 分别核对的内容 |
|---|---|
| 实验原理（简述、原理图及主要公式） | 机制简述；原理图及标注；主要公式、量定义及适用条件。 |
| 实验目的 | 与实验内容对应的具体目标。 |
| 数据记录表（自拟） | 按测量分组设计表头；量和单位；原始值、初始位置及必要仪器记录。 |
| 实验方案及仪器（实验方案、主要仪器及操作要点） | 方案；仪器；操作要点，三项均有内容。 |
| 实验过程及现象（操作顺序、观察到什么现象、遇到哪些问题、如何解决） | 操作顺序；实测现象；有依据的问题；实际处理及效果。无问题记录时待补，不能编造经历。 |
| 实验数据处理及结果 | 按本次教师/用户要求检查公式、关键步骤与代入、结果、物理结论及附页图号；不得只有图或结果表。 |
| 实验总结及讨论（实验收获、反思及思考题解答） | 收获；依据数据的反思与改进；题目逐条解答。写了总结段不等于完成思考题。 |
| 应用延伸与拓展（日常相关的应用或与自己专业相关的研究） | 按模板“或”的关系提供有依据的应用；用户要求两类时再分别写，未知专业不猜。 |

空间预算用于安排内容，不能用空间不足删除必填项。参照PDF先覆盖完整要求；必要时题解另附页，并在对应栏目明确引用。手写精简稿仍须覆盖各必填项。

## 题目清单与阶段对应

教材优先，补充当前课程PPT和用户提供的题目，区分课前题、实验后思考题、步骤中的观察问题、选做进阶题。每题保存题号或简短主题、阶段、来源定位、适用范围及成品位置；不能把某次实验的题数固定为所有实验通用规则，也不能把选做题改为必答。

- 完整实验后报告包含模板要求的思考题解答，即使预习文件已经答过，也需在正式报告中作答，或按教师/用户允许的方式明确引用附页。不能凭另一个文件有答案就勾选正式报告完成。
- 指定模块任务只处理该模块关联的题目。题干缺失须指出并核对，不猜测补题；独立计算和其他模块继续。
- 读取教材题目并离线写题解，与浏览器观看慕课、答题或提交是不同任务。仅用户要求时进行慕课操作，不因此跳过已要求报告中的思考题。
- 题解先给结论，再说明原理或计算，适用时联系实测现象；区分理论预期与已观察事实。

## 检查实际交付文件

逐项对照最后导出的PDF或用户指定成品，记录准确页码/图号。仅在草稿、聊天、缓存、另一份预习文件或旧版PDF中出现的内容，不算当前成品完成。栏目标题存在不等于括号中的内容都存在。

含公式的新增题解先LaTeX编译并查看实际渲染。修订旧PDF时，核对新题解及栏目指向，同时确认数据、图号、页码和其他正文没有意外丢失。内部验收还需确认未将通常问题写成本人故障、未移植参考报告数据、打印区无工作提示。
