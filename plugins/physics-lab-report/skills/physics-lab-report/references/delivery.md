# 交付与归档

本次工作目录由用户指定；默认按实验名分组，不硬编码维护者目录。原始材料只读，生成文件写到独立工作区。可交付报告PDF、Excel、MATLAB `.m`、图形PNG/矢量PDF/FIG；按用户需要选择，不创建无用空文件。

成品正文、公式、图片及表格必须位于报告模板对应栏目中；篇幅较长则续接同版式页。逐页按100%实际尺寸检查正文、图标注、表格数字及真实文字盒边界。只交空白模板或脱离模板的文章PDF，不满足默认交付要求。字号和图文排列以 [模板内成品排版](template-filled-output.md) 为准。

验收前按 [栏目要求与验收](template-requirements.md) 逐项核对实际成品并记录位置；栏目标题存在不代表括号中的子项齐全，预习文件已答不自动算正式报告完成。

验收：所需模块及指定思考题完整；问题与处理有事实依据；公式、单位、有效数字和归一化一致；Excel→MATLAB→图→正文采用同一确认版本；附页图号确实指向最新版；手写稿未超过独立分区预算；打印内容无任务提示；实际PDF已检查，MATLAB运行状态如实说明。

移动前检查目标文件冲突、校验复制前后哈希、确保脚本相对Excel路径仍可读。删除只针对明确授权的本实验中间文件，不波及教材、参考报告、其他实验、技能模板、密钥配置或共享依赖；知识缓存默认保留，用户指定清理才删除。不要自动删除可编辑报告源码。
