# 空白报告模板与测量依据

`assets/blank-report.tex` 是四页独立LaTeX源文件，`assets/blank-report.pdf` 为实际编译的210×290 mm空白报告纸。校徽和校名字样的轮廓嵌入TikZ，无需联网、外部图文件或系统中文字体；使用XeLaTeX编译。预习页原二维码位置使用用户提供的图片占位，第二页原二维码仍删去；保留学校题字、身份填写栏、完整栏目及括号要求、星号、横线、页码、教学中心名称和网址。第三、四页没有额外页眉。素材出处记录在 `assets/brand/provenance.json`。

`assets/template-geometry.json` 存放横线数量、起点、间距及栏目所在行。几何校准流程为：校正照片方向，执行准确中文OCR，识别横线，结合透视估计，以照片逐页复核全文与视觉位置。正文采用可检索文字，品牌轮廓由学校官方透明PNG转换；不是把照片铺满PDF，也不是凭印象重新设计。

照片有起伏、边缘裁切和透视，不能宣称已经达到扫描原件的逐像素一致或毫米级套印精度。需要真正套印时，使用平板扫描或已知尺度的正俯拍重新校准。打印使用210×290 mm纸张、100%实际大小；使用A4纸时保留实际尺寸，不启用适合页面缩放。

`assets/report-space.json` 对应当前模板，预习页占位矩形固定为 `[173,246,21,22]` mm（纸张左上角为原点）；原图等比例21×21 mm，位于 `[173,246.5]`，不拉伸。`reserved_areas` 与实际图位置一致，并留1 mm图文间隙。表格、文字和原理图不能覆盖这个区域；图片左侧剩余宽度可以继续书写，不扣掉整个底部行。填充工具会拒绝与占位区域相交的块，默认全宽数据块在图片上方截止；长表拆成上方全宽、下方左侧窄表或续页。原PNG未修改，保存在 `assets/corner-placeholder.png`，LaTeX内嵌图案轮廓以保持独立编译，位置及来源记录在 `assets/corner-placeholder.json`。其他页面沿用原版含二维码纸张时，再读取 `source_photo_qr_reserve_mm` 校准避让。

重新排版时先保留各栏括号中的全部要求，并检查思考题清单。模板字号只复刻印刷栏目文字，不代表用户手写字的大小；参照PDF的内容详实度也不能被空白纸的几何预算限制。完成新模板后实际编译、渲染四页，对照原图核对文字、行数、字段、标志形状、页脚及二维码处理，再同步PDF和几何模型。不要仅凭编译成功交付。
