# 参照PDF、手写稿与公式交付

## 成品与参照稿

正式成品及完整参照PDF默认都排在实际报告模板上，规则见 [模板内成品排版](template-filled-output.md)。正文、公式、小图及表格必须落在对应栏的可写区域；更多解释、推导、完整数据表和题解接同版式续页。不能先交空白模板，再把正文排成另一套普通文章版式。

完整参照稿覆盖教材的机制、符号、条件、原理图、公式、关键推导、计算步骤、结果、比较、误差讨论及必答题，并在核心信息之外保留有依据的补充，使内容量和详实度超过预计手写空间。模板容量用来安排主栏与续页，不作为删掉教材内容的理由。增加的内容必须有价值，不用重复、套话或无依据经历填充。

只有用户要求时才提供手写精简稿，依据真实图文布置筛选；先保留必需项，再删重复，仍写在模板上。只要求一个模块时只填该模块及必要续页，不生成其他模块。长数据分析图可以作为正式附页，正文保留公式、关键代入、结果、结论和图号。

模板内正文先从9.5 pt起步，继承各栏横线节奏；印刷标题、身份标签和校徽不变。图题与图内标注、紧凑表格有单独参数。10.5—11 pt是两份不同电子版式前人正文的测量值，不再作为当前模板所有正文的强制默认。字体、图表大小均以100%实际尺寸检查；不可为了只留四页而缩到难读。

## 教材优先与内容完整性

先读对应教材章节，再列该模块的内容清单：物理机制、公式及条件、量与单位、原理图、测量项目、处理方法、题解。当前教师/PPT对实验实施的明确变更另行核对记录。前人报告用来参考书写密度、图表形式与可能的讨论角度；不能用它覆盖教材、因其未写就省去教材要求，也不能将其结论当作本人数据证据。若有冲突，返回教材核实，不以参考报告数量投票。

规划时建立“来源要点—输出位置”对应关系。每条必须内容至少有一个明确位置；核心公式和量定义优先放原理，处理区直接引用并给本次代入，避免整段原理重复。总结解释结果和局限，不重抄步骤；题解按原题逐一核对。不遗漏是内容完整，不等于把教材逐字抄入所有栏目。

环境缺失时先按 [环境检查与替代路线](environment.md) 提供一键安装或真实可编辑源文件。

## 公式必须经过LaTeX编译

凡交付PDF中含科学公式，先将其写成合法LaTeX数学环境，再实际编译并检查，最后交付编译产物。不能把Markdown的 `$...$`、`\\frac`、原始LaTeX字符串或模型文本直接当作PDF正文；不能用未经数学排版的Unicode符号堆叠代替分式、上下标和根式。

- 行内公式用 `\(...\)`，模板正文内公式随文字连续排列、按行宽自然续行，保护紧密数学结构；脱离行格约束的附页才用独立/编号公式和 `aligned/align`，单位用直立体，变量含义写清楚。
- 源文件已在编辑器打开时原位编辑；用内置 `compile_latex_document` 做诊断。其他TeX工程使用适用的LaTeX编译技能和已安装编译器；不要把编译失败的源文本直接转成PDF交付。
- 需要Word等流程时，先用LaTeX编译公式再作为可读的矢量或足够清晰的公式资源嵌入，或者改用完整TeX工程；不能只更改输出扩展名声称公式已排版。
- 内置编译成功不等于磁盘PDF已更新。真正导出的PDF必须与当前源文件和图版本一致；检查修改时间、页数，并渲染实际成品。
- 逐页检查公式：分式、根号、上下标、希腊字母、负号、角度、单位、矩阵及对齐；不得出现未解析的命令、缺字方框、公式图片糊掉或裁切。文本提取只能辅助检查，不能代替查看渲染页。
- 无法编译时保留源文件并明确当前限制，提供可编辑内容，不宣称已交付合格公式PDF。

交付前同时做来源覆盖检查、数值一致性检查、内容重复检查与公式渲染检查。单纯“编译通过”或“页数符合模板”都不能替代这四项。
