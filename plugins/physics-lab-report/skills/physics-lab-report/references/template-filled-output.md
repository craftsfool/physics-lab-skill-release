# 在报告模板上排成品

## 输出形式

默认正式成品必须以 `assets/blank-report.tex` 的真实报告纸为底板，将正文、公式、原理图与表格写进对应可写栏。单独交付空白模板，再将正文放在另一份普通文章PDF中，不算完成此要求。保留原有校徽、题字、填写栏、印刷栏目、括号说明、横线与页脚；不另加大字号文章标题或任务页眉，不把未知姓名、学号等字段填成虚构值。

用户只要求一个模块时只填该模块并输出相应模板页；预习与实验后报告遵循实际阶段。完整参照稿也排在模板上：前四页放必需内容，更多解释、完整表格、推导和题解可接同版式续页，标题用“实验原理（续）”“不确定度分析（续）”等实际内容名称。正文保留公式、代表代入、计算结果、结论和明确的附页图号；不能将计算步骤全部移到附页。内容量和详实度仍应超过预计手写容量，留有选择余量；这一要求通过有价值的续页实现，不靠重复、缩到极小字号或侵入下一栏。只有用户要求精简时才筛选内容。独立数据分析图附页沿用用户已要求的MATLAB/Origin图式。

## 样本依据与推荐参数

四份同类纸质手写报告用于观察密度和图文排列，两份电子报告用于测量已有字体及图片尺寸。电子报告正文主要为10.5—11 pt，图片实例为35.5×30.2、81.2×39.3、101.4×52.9、146.5×52.3 mm；它们是另一套A4电子版式，不能当作210×290 mm报告纸的精确容量。手写扫描件没有真实“字体pt”；约2.6—3.5 mm字宽和小图尺寸属于视觉估计。下面是将这些排版习惯迁移到当前模板的默认值，明确区分测量结果和设计选择，细节保存在 `assets/report-typesetting.json`。

| 对象 | 默认排版 | 调整与限制 |
|---|---|---|
| 模板固有标题、栏目和身份栏 | 沿用模板17、14、11.5 pt等参数 | 印刷栏目字号不能作为正文、手写字或图标注字号。 |
| 填写正文 | 宋体/可用等效字体9.5 pt，首行缩进1字，段间0额外空行 | 通常9—10.5 pt；紧凑8.5—9 pt只有在实际尺寸清楚可读时采用。不要为了塞满四页不断缩字。 |
| 栏内小标题与短编号 | 与正文同号，可加粗 | 不再使用普通论文的16—20 pt标题；不每节机械空一整行。 |
| 行内及主要数学公式 | 9.5 pt，与正文接近 | 短公式、代表代入及单位可同一行；短等式优先行内排，必要时采用斜杠或小型分式；复杂矩阵按真实高度另作局部图式，不固定扣两行。 |
| 表格 | 8.5 pt；紧凑行高约4.5—6.5 mm；单位写在表头 | 多行单元格另增高度；手写参考不少表格一行约8 mm，不能声称都测为4 mm。长表另接续页，保留全部实测值和精度。 |
| 图题与图内标注 | 8.5 pt，通常8—9 pt | 图中文字缩放后仍须可辨；7.5 pt只是小图标注的下限，不是所有文字的默认值。 |
| 已知身份信息 | 9.5 pt写入对应填写线 | 过长时合理换行或由用户确认简称，不能覆盖印刷标签。 |

填充工具将正文的行距倍率固定为1，并按TeX点（72.27 pt/in）换算毫米，防止文档类默认行距倍率再次放大实际行距。填写正文的字面落在行格下部，基线贴近该行下方横线，纯文字默认在下线之上0.8 mm，含数学段落默认1.8 mm；不能把文字顶在上线附近。首行先选足够容纳字面的下一条下线，再按该栏8.1或8.4 mm的横线节奏续排，包含首行下移后的真实高度仍须不超过预留区域。图题、表格可独立使用约4—6 mm的内部行距；不要从这种局部紧凑排列推断每个正文栏都能写两倍行数。以100%实际尺寸查看，区别字面大小、字宽、基线间距和分式高度。

## 图片、原理图、表格与文字环绕

同版式样本常见的小电路图与公式并排、右上角光路图旁继续说明、多个小轨迹图成组排列、两三组数值表并排。复用这些布局思想，不复制前人的数据、姓名、结论或越界位置。

- 简单原理图先试35—65 mm宽、15—30 mm高；复杂图按元件、箭头、量标注实际增大，不规定所有图一个大小。
- 裁去图像空白边框和软件大画布，保持长宽比；不得为凑版面拉伸图片。图本身与图题分开预留实际矩形。
- 窄图靠左或右，旁边继续写文字、公式与量定义，图文间隙通常1—2 mm；图结束后恢复全宽。可以显式拆成“旁排文字块＋图块＋下方全宽文字块”，不要依赖绝对定位中的浮动体或把全文整段空出三行。
- 两幅对照图可并排，各约75—85 mm宽；标注多时改成纵排或附页。数据分析图常需85—174 mm宽，不能按小手绘图压缩到看不清图例、误差棒和拟合参数。
- 简短数值表可以两组/三组并排；根据最长数字和单位计算列宽，不单凭表格外框是否放得下。两侧矩形确实留有余量时才旁排说明。
- 预习页右下角 `[173,246,21,22]` mm占位图片固定保留，外围1 mm也不能进入；其左侧可排窄表或文字。同栏正文、图、表、图题之间不重叠，不进入下一模块、身份栏或页脚。参考稿中的跨栏、写到纸边和覆盖二维码是排版问题，不能学习成推荐方式。

## 沿横线连续书写公式与推导

正文、推导和短公式组成连续段落，按剩余行宽断行，不按等号、推导步骤或每个结论强制另起行。只在真正转入另一小节或题目时换段，段间不插空行；同一题的条件、代入、数值和判断接着写。行尾大段留白时，先把下一句或量定义接上，检查是否由人为换段或预留块过大造成；不能用拉大字距掩盖空白。

不可拆的是连在一起才有数学意义的字符与结构，不是整条等式。等式和链式推导随行宽连续写，放不下时允许在等号、加减号、乘号等合适位置自然续到下一行，不把整个等式提前搬走。`\LabMath{...}` 为可断行的行内数学；分式、根式、上下标、函数名及其紧密自变量、科学计数法的数值与单位保持整体，可用数学分组 `{...}` 或局部 `\LabMathUnit{...}` 保护。不得对整条推导使用 `\mbox`。不得拆开一个数字的各位、变量与下标、函数名、数值与单位，也不在紧密结构内部插入人为换行。

模板正文与公式块共用8.1/8.4 mm的横线节奏。`formula`角色同样对齐下线，不用居中的 `\[...\]`、`align/aligned` 多行推导或 `\\` 逐条断行占用多格。独立白底公式盒会擦掉底线并造成大块空白，应改成透明的行内数学。正文基线默认距下线0.8 mm；含数学上下标、分式的段落默认提高到1.8 mm，可用 `rule_clearance_mm` 按实际字面微调，防止下标穿线；仍保留固定横线行距。复杂矩阵或结构图使用明确量高的局部非正文块，不把普通推导改作图片绕过行格约束。

图表旁用互不重叠的窄正文块连续排字，图结束即恢复全宽；不因一个小图让后续正文整段另起页。页与栏的内容保持完整；先整理连续行文和实际尺寸，再考虑续页，不能删掉教材内容、思考题或计算细节来制造紧凑效果。

数字、数学符号及中英文边界使用紧凑间距：`\mathsurround=0pt`，数学薄空默认1.5 mu、中空/关系空2 mu，中西文边界固定约0.2 em，以当前字号自然汉字的视觉字距为参照。正文统一左对齐、自然字距，不使用两端对齐或分散对齐拉伸汉字与词间空隙，也不在不同行之间切换间距策略。行尾只留不足以容纳下一数学结构或字符的自然余量，不靠拉大空隙把右边缘凑齐。数值与单位仍保留薄空；不能用负字距把上下标、负号、等号或相邻数字挤在一起。固定字距的紧密数学结构保持整体，不靠拉开符号填满行尾。

验收既看编译是否成功，也看实际PDF字面：正文与公式基线是否按横线等距递增、上下标和分式是否跨线、是否有公式白底擦线、是否有紧密数学结构被拆断、是否因硬换行留出大量空白。核对重新导出的PDF与同源TeX，避免只修改预览未更新磁盘成品。

## 可复用的LaTeX填充方式

运行 `scripts/fill_report_template.py --content <content.json> --output <report.tex>`，生成以模板为底板的独立TeX及布局清单。正文和所有公式须在TeX中实际编译，再交付PDF。脚本只放入用户授权内容，不自动撰写实验数据或提交报告。

`content.json` 支持 `experiment`、已知的 `identity`、`regions`、`continuations` 和 `page_selection`。栏目ID见 `assets/report-space.json`。区域值可以直接给一段LaTeX，也可以给 `blocks`：每块包含 `latex`、`role`，可选 `font_pt`、`baseline_mm`、`rule_clearance_mm`、`rect_mm`、`background`。矩形 `[x,y,w,h]` 的单位是mm，坐标从该栏目印刷标题及括号说明以下的正文区左上角算起；脚本会预留上下间隙。角色支持 `body/formula/table/caption/diagram`。`background` 支持 `white/none`；正文与公式默认透明，不用整块白底抹去虚线。仅图、表可按实际矩形避开底线；白底不得遮到其他块或印刷栏目。

```
{"experiment":"实验名称", "page_selection":[1], "regions":{
 "principle":{"blocks":[
  {"role":"body","rect_mm":[1,0,111,24],"latex":"此处为经过核对的原理、公式和量定义。"},
  {"role":"diagram","rect_mm":[115,0,55,24],"latex":"此处放入实际原理图的TikZ代码或保留比例的图片。"},
  {"role":"body","rect_mm":[1,26,171,33],"latex":"此处恢复全宽，继续写必要条件和主要公式。"}
 ]}}, "continuations":[{"heading":"实验原理（续）","latex":"有依据的补充推导、讨论或题解。"}]}
```

示例中的文字只说明输入位置，绝不能作为正式报告正文。图表尺寸按本实验调整；正文矩形的高度应容纳编译后的整块内容。需要图文混排时优先用互不重叠的块和紧凑 `minipage/tabular/TikZ`；不要用 `figure/table` 浮动环境破坏绝对定位。公式先编译，图题和脚注也必须计入边界。

脚本拒绝越界、矩形相互重叠、不合理字号及行距；编译时测量每个文字盒的真实高度，超过预留高度则报错。修改块大小、重新拆分或移至续页后再编译，不关闭检查、强制裁切或交付部分PDF。布局清单不是编译成功的替代物。实际字体、表格及长公式仍可能产生横向溢出；编译日志中的 `Overfull \hbox/\vbox`、裁切和越界必须修正，再检查PDF。嵌入块中的LaTeX是可信排版输入，不直接执行API返回的代码。

交付前逐页检查实际PDF：模板边界保留、各栏内容可读、无盖住印刷文字或横线穿过字面、公式正确、图比例正常、图表编号真实、所有括号要求与思考题落实、引用确指最新版图。检查篇幅是否因错误图块或过大字号而过少；教材要求、用户数据及完整题解的优先级高于套用前人篇幅。相同输入须生成同一版内容与数据，不把可视化示例里的数值当作本次结果。
