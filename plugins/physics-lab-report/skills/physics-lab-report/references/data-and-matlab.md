# 数据转录、处理与MATLAB绘图

## 原始记录到Excel

1. 看整页识别实验分组、行列对应、角度/电压/电流定义和单位，再放大局部识别。保留原图，记录涂改位置与候选读数。
2. 把真实零值、未记录值和看不清的值区分：真实0保留0，缺失留空/NaN；不能用曲线插值或理论值填成实测值。原始绝对刻度、相对角、累计角与方向夹角分别命名，周期折算不能覆盖原始数值。
3. 批量询问关键模糊读数，避免反复逐点询问。待确认值不悄悄进入正式结果；可以明确做临时敏感性分析。用户订正后重算所有相关结果，而不是只改打印表。
4. 按当前 spreadsheets 技能建立工作簿：一张原始数据表或分组表、一张处理/结果表；表头单行、单位清楚、数据为数值型，不用合并单元格阻碍MATLAB读取。保留稳定字段如 `Group`, `Angle_deg`, `Power_mW`, `Status`，或按实验自定英文列名并提供含义。
5. 原始列、换算列、公式列和汇总分开。检查原始数值逐点对应、缺失数量、公式错误及缓存值。回归/模型结果若是程序快照而非Excel公式，标明重算方式。

## 计算和误差

写清公式、单位换算、一次关键代入和最终单位/有效数字；大量同类计算不用逐个展开。拟合参数同时记录数据范围、样本数、模型、归一化基准和是否含截距。不要假定最大值等于独立标定的入射量，也不要无说明地让每组分别归一化后比较绝对大小。

理论比较使用正确物理角/参考零点；正负、180°/360°周期及峰位折算要有定义。R²高不证明理论完全正确；线性斜率接近0不证明周期变化为常量。采用加权拟合须有权重依据，不默认给所有仪器读数同样的已知方差。

误差限不能直接当标准不确定度；假设均匀分布时用误差限/√3并写明假设。功率计量程决定的精度不明时，不根据小数位数猜量程。扫描不同角度产生的标准差不是同一点重复读数的不确定度。回归标准误与包含仪器误差的合成不确定度分开。

## MATLAB真实执行

先检查用户应用和可用安装，缺少MATLAB时按 [环境检查与替代路线](environment.md) 选择Online、Python或Excel。优先用CLI或其他稳定接口运行现有脚本；确需操控界面时用Computer Use工具。不清空或关闭用户无关工作区、图窗，也不擅自改MATLAB永久首选项。

脚本读取自身所在目录的Excel，以原始列重新计算；不依赖当前工作目录、不依赖先运行Python生成的缓存、不把上次结果写死。缺失量明确过滤。可使用 `readtable`、矩阵最小二乘/`polyfit`，按实际模型选择；不为了外观把周期数据拟成直线。

`scripts/lab_origin_style.m` 提供图形外观和PNG/PDF/FIG导出，作为辅助，不代替实验专用模型。把它放在实验脚本同目录或加入本次路径即可；分析脚本要写明数据列和物理意义。

实际执行后查看错误、导出文件和关键拟合参数，检查结果与Excel一致。没有MATLAB运行条件时提供可复算代码并如实说明未实跑；Python/PGFPlots生成的图不得称为MATLAB图。

## 参照Origin/PPT示例

- 先匹配横纵量、单位、归一化、极坐标/线性坐标、拟合模型和误差条要求；再匹配外观。
- 默认黑色实测点、红色拟合线、蓝色虚线理论，白底、向内刻度、简洁边框、易读字体。点线连接是观察引导，不当作拟合；非有序自变量先排序再连线，马吕斯的cos²自变量重复时通常只画散点。
- 若用户要求拟合与理论比较，同图图例分别标识。理论幅值经过实测缩放必须在图注说明，不能说成独立理论预测。
- 只有一个测量点的组不能拟合整圈曲线；可以标实测点与明确假设的理论曲线。不要伪造对称点或复制整组数据。
- 参数表可含模型、截距/斜率、标准误、R²和n；不要把工作提示写进图，例如“PPT example”“required”。
- 输出300 dpi PNG、矢量PDF、可编辑FIG及 `.m`，每图检查坐标、图例、边界和参数框。导出前隐藏坐标轴工具栏。

## 单一数据版本同步

每次更正后按“Excel原始列→MATLAB计算→图和拟合汇总→报告数字与图号”更新。文档不得继续嵌入旧的蓝点图、未连线图或旧示意曲线。内置LaTeX只能编译单文件时，可用同一确认数据与参数绘制内嵌PGFPlots；承认它是内嵌重绘，视觉样式及量关系与最新版保持一致。
