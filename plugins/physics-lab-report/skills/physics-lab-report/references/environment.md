# 环境检查与替代路线

开始时运行 `python3 scripts/setup_environment.py --project <用户指定项目目录>`。脚本使用Python标准库，检测PATH及常见安装位置，不联网、不打印令牌。默认检测不创建目录；用户明确选择本地资料后才运行 `--local-materials`，新建目录不会覆盖已有文件。不存在Python时，先使用宿主提供的Python运行时；仍不可用则由AI按本页做检查和创建文件夹，不声称脚本已执行。

## 没有资料API或没有教材

先读取共用引导中已确认的来源：`none` 不创建目录，`local` 仅在指定项目创建目录；`api` 未配置成功仍说明待配置。默认检测脚本返回的待选择标志不覆盖用户已记录的选择。

没有API端点/令牌时，脚本返回 `requires_reference_choice: true`、`reference_mode: awaiting_user_choice` 和建议问句，不创建项目或资料目录。AI必须告知用户未检测到配置，并询问选择“登记设备领取30天Key”“配置已有API令牌”或“使用本地资料/不提供参考资料继续”；设备登记按 [设备与章节](device-and-chapters.md) 执行。在用户答复前不得创建空白目录、擅自切换来源或搜索本机报告。用户选择是必要输入，等待不能视作同意；期间仍可处理已提供数据、模板等独立工作。此前已明确选择本地模式或明确提供本地材料时，沿用该选择，不重复询问。

选择API时说明维护者提供端点及个人令牌，必要时还有平台访问凭据；让用户通过私密配置/环境设置，不索要聊天中的令牌，不打印凭据。配置完成后重新检测并按需测试一个模块；未配置成功不假装已接入。选择本地资料时才运行 `python3 scripts/setup_environment.py --project <项目目录> --local-materials`，在用户项目内创建空白 `教材/`、`前人智慧/` 文件夹，并告知位置和可放PDF、Word、PPT、图片等。只能读取用户明确提供/指定的材料，目录存在不等于获准扫描其他位置。

API有配置但401/403/429/5xx时说明失败，询问修复API配置或改用本地/无参考资料；不绕过认证，不自行创建目录。按原有重试及配额规则处理。用户先前已经授权失败时走本地路线的，可以直接沿用。不能以空目录冒充已获取参考资料。

材料缺失时仍运行模板、转录、单位换算、计算、作图和已有内容整理。先列“已知—缺失—可独立推进”，只有影响当前成果的必要信息才向用户询取：实验名与测量项目、原始数据及单位、处理公式/物理模型及适用条件、关键仪器参数/量程、教师指定题干或图要求。已有信息不重问。不必为了写一个模块要求全部材料齐备；只有无法确定的计算或实际现象保留待补，独立内容继续完成。通用物理分析标明依据和条件；不给未读材料编造页码或题目，不编造用户数据。教材与前人报告均没有时，也不能退回搜索维护者私有目录。

## 没有LaTeX

先区分：没有终端TeX，但宿主内置编译器可用；有编译器但缺中文字体/宏包；完全没有编译器。实际调用一次小型中文公式或本次源文件验证，不能只凭PATH推断“无法编译”。内置编译诊断不一定导出磁盘PDF。

完全缺失时告知：“本机未检测到可用LaTeX。可为你一键安装TinyTeX及中文模板所需宏包，或者先保留可编辑源文件。”先说明需要联网、用户目录安装及下载内容，获得安装授权后执行：

```
python3 scripts/setup_environment.py --installation-plan
python3 scripts/setup_environment.py --install-latex
```

用户明确要求安装或执行该按钮/命令即为授权，不重复确认。不得在仅撰写报告时静默安装。脚本下载[官方TinyTeX安装器](https://yihui.org/tinytex/)，macOS/Linux传 `--no-path` 不修改全局PATH；Windows使用官方批处理安装器。Linux需要已有Perl和xz，Windows需要PowerShell；缺失时明确提示，不能虚报成功。补装模板所需ctex、Fandol、TikZ/PGFPlots等包后检测XeLaTeX。遇网络、管理员权限或安装失败，保留现有内容，给出失败原因及手动安装入口，不反复执行或更换未经核验的镜像。

已保存独立TeX可用 `python3 scripts/compile_report.py <report.tex>` 实际编译两次并导出PDF；失败或内容越界时不覆盖现有PDF。没有该脚本所用XeLaTeX但有可用Tectonic/内置编译器时采用已有能力。多文件图文工程必须用支持依赖的编译器。PDF交付前渲染检查，不用原始公式字符串、截图乱码或更换扩展名绕过公式排版。暂不安装时交付真实可编辑内容并说明PDF尚未编译。

## 没有本地MATLAB

- 用户明确要求MATLAB：提供[MATLAB Online](https://matlab.mathworks.com/)路线及 `.m` 和数据文件，用户登录后可经Computer Use运行；登录、许可或额度由用户自行处理。Online版本条件以[MathWorks说明](https://www.mathworks.com/products/matlab-online/matlab-online-versions.html)为准，不承诺永久免费/无限使用。未获用户同意不上传其数据到第三方服务。
- 用户只要求正确计算和图像：本地Python优先，numpy/scipy负责拟合和不确定度，pandas/openpyxl读Excel，matplotlib输出PNG及矢量PDF。先检测已有依赖，不为了缺MATLAB强制购买或下载。缺依赖时提供隔离虚拟环境安装命令并按安装授权执行；不改变系统Python。保留可从原始表重算的 `.py`，实际检查导出图，标明Python生成。
- Excel可用于单位换算、统计、线性拟合、散点图；提供可复制公式或真实工作簿。非线性拟合、极坐标和误差传播以模型与功能支持选择工具，不能把线性趋势线用在所有数据上。已知模型需用弧度时明确 `RADIANS()`。
- GNU Octave可选，但须核对工具箱、Excel读取和绘图导出兼容性。必要时使用CSV作输入，不能声称它就是MATLAB。

工具可用性只改变执行路线，不改变原始数据、拟合模型、理论条件和图中的实测/拟合/理论区分。检测到MATLAB路径不等于许可证或工具箱可用，执行失败时按替代路线处理。始终如实记录实际执行工具、未执行的代码及需要用户完成的步骤。

## 可直接执行的替代计算

线性模型已确认时，用户CSV可直接执行，无需额外Python库：

```
python3 scripts/analyze_table.py data.csv --x x --y y --output results
```

读取Excel改为 `data.xlsx --sheet Sheet1`（需openpyxl）；可用 `--x-scale`、`--y-scale` 显式单位换算并用 `--x-unit`、`--y-unit` 标明换算后单位。`--plot` 在已有matplotlib时输出图像；脚本不静默安装依赖，不使用API资料作为数据。输出拟合系数、标准误差、R²及残差表；普通最小二乘标准误差不能直接替代总不确定度。至少三对有效数据，异常点不自动剔除。非线性、加权或自变量误差显著的模型另写适当计算代码。

Excel线性路线：`=SLOPE(B2:B11,A2:A11)`、`=INTERCEPT(B2:B11,A2:A11)`、`=RSQ(B2:B11,A2:A11)`；用 `LINEST` 获取回归统计。列范围按真实数据改写，空白/文字不能冒充测量零值。建立散点图并添加拟合与理论，角度计算按公式使用 `RADIANS()`。
