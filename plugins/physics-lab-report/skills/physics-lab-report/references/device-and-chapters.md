# 设备 Key 与教材章节预览

## 设备登记

无需 OpenAI Client ID、OpenAI API Key 或 KOOK。先告知用户：首次登记将在本机保存设备私钥和30天资料服务 Key，服务端保存公钥及授权记录；同一凭据重复登记不会续期或重置用量。得到资料来源选择后再执行，不把安装插件当作已经选择设备登记。

使用现有 Node.js（可使用宿主提供的运行时），不自动安装软件。脚本路径相对报告技能解析：

```
node scripts/device_client.mjs status
node scripts/device_client.mjs register
```

登记成功只输出凭据文件位置、到期时间，不输出私钥或 Key。默认文件在当前用户配置目录的 `physics-lab-report/device.json`，macOS/Linux权限0600；`PHYSICS_LAB_DEVICE_CONFIG` 可指定宿主允许的私密配置位置。不要把该文件写进报告工程、版本库或知识缓存。私钥保存在执行环境，不是硬件不可导出的凭据；复制该文件可以复制使用权，删除后新登记可能重新领取，这一限制已被维护者接受。

同一设备凭据30天到期或被停用时不可重新领取续期；需要维护者处理。没有持久执行环境时，不宣称绑定了用户电脑，可使用用户已有的私密令牌或本地资料。插件不读取机器序列号、OpenAI登录状态或浏览器账户来识别用户，不硬绑定IP。

选择设备来源后，执行 `onboarding.py choose-source --reference-mode device`。后续查摘要：

```
node scripts/device_client.mjs fetch --experiment grating --library textbook --topic theory
```

或使用 `python3 scripts/fetch_reference.py --device ...`。摘要只进入当前任务上下文，不重定向落盘。所有设备请求同时带 Key 和短时签名证明，复制 Key 本身不能发起设备鉴权请求；请求重复发送会被拒绝。

## 在线预览课本章节

用户要求看教材原文时，按实验短ID申请一个章节预览入口：

```
node scripts/device_client.mjs preview --experiment grating
```

返回标题、页数、5分钟有效的 `preview_url`。用宿主浏览器打开，或将链接交给用户；**不要使用网页抓取/链接检查器预取这个一次性入口**。首次打开后转入同站点临时阅读会话，浏览器展示原始章节PDF。宿主浏览器不可用时给出可点击链接；链接已被消耗或过期可重新申请。

每个入口仅对应一个实验的教材章节，不返回完整资料库目录、原始存储地址或访问令牌。发起预览会消耗一次普通请求额度（仍预留2400字符额度），阅读会话的后续加载不重复计费；页数和PDF内容不适用摘要2400字符长度上限。每次加载重新核验Key状态、到期和章节授权；浏览器会话最多5分钟，已经加载进浏览器的内容无法撤回。

在线原文预览是独立授权能力 `chapter_preview`，旧令牌未获该授权时会403；前人报告不在原文预览范围。只有已登记发布的18个教材章节可预览，新增章节要经维护者显式发布。服务器转发私有PDF，不在插件或公开静态目录附带教材。可阅读的PDF可能被浏览器保存或复制，不能宣称只读防下载或绝对不可复制。用户项目中不自动缓存教材PDF。
