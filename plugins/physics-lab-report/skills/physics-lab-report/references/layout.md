# 手写容量与四页报告纸

## 先对照手写报告，再定篇幅

纸张为210×290 mm，栏目边界保存在 `assets/report-space.json`。约173—174 mm可写宽度、各页约8.1—8.4 mm印刷横线间距来自照片，不能把横线间距当作字高，也不能把电脑正文的字号、段前段后距或独立公式环境直接换算成手写行数。

先观察用户自己的字迹；其次参考同一模板的前人报告。既要看文字密度，也要看小原理图、并排公式、紧凑表格和文字环绕。优先对应实验；缺少对应实验可用同一报告纸的其他实验校准空间，不能用其数据与结论填入本实验。无参考时才使用默认档位，明确是估计。获取参考资料前只能建立几何分区，取得参考后的容量校准必须在确定正文篇幅之前完成。

当前默认字宽3.0 mm，每整行约57个全角字符当量；紧凑档2.6 mm约66字，较大字迹3.5 mm约49字。由相同版式手写报告的视觉比较得到这个暂定范围，不是对用户字迹的精确测量。汉字、标点、数字、英文和公式宽度不同，实际换行要检查。正文基线间距按对应栏目约8.1—8.4 mm估计，不默认一条横线写两行。

旧模型的4.4 mm字宽、每栏至少扣一行、独立公式固定扣1.5—2行已取消。默认按可用字符当量保留约5%余量，不再让短栏目因整数取整丢掉一整行。容量只是手写布局估计，不是参照PDF的篇幅上限，也不是要求写满。完整内容不足时不凑字数；需要解释、推导和结果依据时也不能先机械删到几句。

## 图、表、公式与文字共同布局

- **原理图**：按可辨认的真实手绘尺寸规划，简单电路/光路可以先试宽35—65 mm、高15—30 mm；复杂图按节点、量标注和箭头实际增大。范围是起点，不是所有图的固定尺寸。图旁保留文字与量定义；图在左或右时允许环绕，不整段留出空白。无需保留软件导出图的大画布与白边。不能把数据分析附图缩成难读的小图。
- **表格**：按列数、单元格最长内容和实际行高计算。简单数值表可先试4—6 mm行高（独立于纸面8 mm横线）；两组短表可并排，窄表旁可写公式。合并重复表头、单位写入列头；保留原始精度、所有必要数据和组别，不能为了紧凑漏列或省数字。多行文字单元格另加高度。
- **公式**：短公式行内或同一行并排；代入、结果、单位可同一行连写；分式和下标只扣实际高度。简单分式未必占两条横线，长矩阵、多行推导才增行。每组仍保留公式、必要代入和结果，不能仅罗列末值。
- **标题与段落**：使用短编号、少量必要换行，不按电脑习惯每小节额外空一行。不得侵入印刷标题、姓名栏、其他模块或二维码。前人样本中的越界、涂改和挤压不是要模仿的布局。

物理模型、符号定义、条件、关键计算、比较、结论、问题及处理的完整性先于篇幅压缩。表格和图只扣其实际矩形及约1—2 mm间隙。逐条计算剩余文字宽度，比“图占三行”准确。

## 栏目与写作安排

| 页 | 模块 | 内容安排 |
|---|---|---|
| 1 | 原理、目的、自拟数据表 | 原理含机制、小图、主要公式及量定义；目的2—4条。表按测量计划编排，题解按教师要求另附。 |
| 2 | 方案及仪器；过程及现象 | 方案含仪器、连接、范围、调节及要点；过程明确操作、观察、问题与处理，只写有依据的经历。 |
| 3 | 数据处理及结果 | 分测量项目写公式、单位换算、代表代入、拟合参数/结果、理论比较、不确定度及结论，指向附页图号。长表及完整回归输出另附，不能把正文处理步骤全部移走。 |
| 4 | 总结讨论；应用拓展 | 总结、误差与改进、指定思考题和拓展按分区安排，解释有足够依据，避免重复原理。 |

先为每个项目安排必要信息，再估算占用；内容显著偏少且缺解释或计算时补足该项，不用套话填满。不设“无论实验如何只能写X字”的硬上限。用户明确要求半页/缩短时服从其要求。

## 空间模型与验收

```
python3 scripts/build_layout_model.py --output <work/layout> --style regular
python3 scripts/build_layout_model.py --output <work/layout> --blocks <blocks.json>
```

支持 `compact/regular/large` 或 `--char-width-mm`。`--blocks` JSON按栏目ID存放图表矩形，坐标相对该栏正文左上角，单位mm。例如：

```
{"principle":[{"label":"原理图","rect_mm":[118,0,55,22],"gap_mm":2}]}
```

脚本输出每条文字基线的剩余区间、整行字数、图表后字符容量和LaTeX示意。它不会自动识别公式高度或决定图形是否够清楚，也不会替代参考手写稿的视觉判断。使用者应填入本实验真实图表尺寸，不用任意示例矩形当作最终布局。

手写内容预览可从约9 pt中文字（字面约3 mm）与对应栏目的约8.1—8.4 mm基线距起步，对照实际字迹调整；该字号不是对用户字迹的测量值。查看时用100%实际尺寸，避免显示器“适合宽度”带来的误判。手写预览与打印附页是两种布局：正式正文仍须写在模板上，附图或续页按 [模板内成品排版](template-filled-output.md) 安排，不能由打印PDF用了多少行倒推手写篇幅。打印正式报告不得出现布局预算、抄写提示或任务文字。

验收同时检查：内容完整、字迹档位、各栏末行、窄图表旁剩余宽度、公式高度、图标注和表格数字可读性。不能只凭编译成功或一页能放下就判定合格。空白模板已用OCR与LaTeX重建，见 [空白报告模板](blank-template.md)。其中文字、线条、校徽和学校题字均为矢量，四页印刷文字完整保留。照片模型仍不能作为经过认证的毫米级套印坐标。

发行版参考材料只通过鉴权API或用户明确提供的本地文件获取。服务端可返回已提炼的字宽范围、占用行数、图表尺寸及布局说明；不在用户项目保存前人报告或原图副本。允许缓存AI归纳的参数和来源索引。附带空白模板为通用重绘版，不能当作学校原版。

参照PDF和手写筛选稿遵循 [参照PDF与公式](latex-and-reference.md)。默认参照内容要完整、有补充与选择余量，不因为空间预算而先删掉教材要点；空间模型用于后续决定如何抄写。

成品不能只按空间预算另外排普通文章PDF。请使用 [模板内成品排版](template-filled-output.md) 及 `scripts/fill_report_template.py` 将实际文字和图表写入模板，检查编译后的真实盒高、旁排区与续页。
