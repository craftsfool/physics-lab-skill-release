# 大学物理实验报告：使用指南

从实验记录到可打印报告，可以只做你需要的栏目，也可以完成整份报告。

**按真实报告纸排版**：正文、公式、图表放进对应栏目，内容超出时使用续页。附带 210×290 mm 四页模板，也可以使用你提供的报告纸。

**修改后刷新预览**：桌面端打开 LaTeX 工程，在宿主内置编译器可用时，保存或修改后自动编译刷新 PDF。编译失败会保留最后一次成功预览，并提示当前修改尚未编译成功。

**选中内容，提出修改**：在支持的预览中选中文字或添加批注，再说“精简这段”“补充这一步推导”。也可以直接引用原文、提供页码和栏目名。Agent 定位到源文件后修改目标内容；计算结果变化时同步必要的表格、图和结论。

**在线预览教材章节**：按当前实验打开获授权的原始章节 PDF，预览入口5分钟有效。无需在安装包中携带教材。

还支持手写数据识别与核对、单位换算、拟合及不确定度分析、MATLAB/Python/Excel 绘图、获授权的教材与参考摘要检索，以及 PDF 和可重算文件交付。实际使用什么工具会明确说明。

## 完整流程

1. **准备材料**：告诉我实验名、需要的栏目，提供模板和原始记录。已有的信息不用重复提供。
2. **选择资料来源**：首次登记设备可领取30天资料 Key（无需 OpenAI Client ID）；也可配置已有的个人资料 API 令牌，或使用你提供的本地材料；也可以先不提供参考资料。令牌通过私密配置输入，不要粘贴到聊天中。这是资料服务令牌，无需额外 OpenAI API Key。
3. **核对与计算**：核对模糊记录，完成单位换算、计算与拟合，使用实际可用的 MATLAB、Python 或 Excel。
4. **生成报告**：完成预习或实验后指定栏目，按报告纸安排正文、公式、图表和续页。
5. **预览与修改**：桌面端在预览中审阅，选中或批注要改的内容；也可以说“修改数据处理栏第二段”。每轮修改后检查编译与版面。
6. **检查与导出**：核验数据版本、公式、图号和排版，交付 PDF、源文件及适用的重算脚本。

## 在不同平台使用

| 平台 | 可用体验 |
|---|---|
| Codex / ChatGPT Work 桌面端 | 宿主具备相应能力时，使用内置 LaTeX 编辑器、自动编译预览及选区/批注修改。 |
| ChatGPT 网页端 | 生成、下载文件，引用文字或指定栏目逐轮修改；按当前环境实际编译能力交付 PDF。 |
| 终端或无预览环境 | 生成并验证文件，报告保存位置；通过引用文字或栏目定位修改。 |

插件不自行增加预览按钮、任意 PDF 框选或远程编译服务。网页端及没有编译器的环境不会承诺实时 PDF 刷新。资料摘要不能代替完整教材，未取得的材料、缺失的测量数据和实际经历不会补造。

随时说 **“使用指南”** 重看流程，说 **“重新设置”** 重新选择资料来源。首次介绍的记录仅限当前可持久化环境，不跨设备同步。
