# 大学物理实验报告：开始使用

读取同插件报告技能的 [首次引导](../physics-lab-report/references/onboarding.md)，按该页共用流程执行；脚本和使用指南也位于 `../physics-lab-report/`，相对当前 skill 目录解析，不能依赖用户工作目录。

先介绍亮点与完整六步流程，再检测实际能力、选择资料来源及询问当前任务缺失信息。仅阅读本技能、安装插件或运行检测不代表用户已经选择本地资料或授权安装软件。已经完成引导时简短报告当前状态并继续；用户明确要求“使用指南”时仍展示完整指南，“重新设置”时清除引导与来源选择后重新引导，不删除凭据或报告。

设置结束可直接继续用户已提出的报告任务，不要求另开聊天或重新描述已知信息。没有持久存储时沿用本会话状态，如实说明不能跨会话记忆。
